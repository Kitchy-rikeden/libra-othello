# Libra the Processor Architecture

Libra the Processor は 5 trit の三進 CPU である.

レジスタ及びメモリアドレスは 5 trit で符号付き, -121 ~ 121 の値を取りうる.

平衡三進リテラルは 0t のプレフィックスを付けて表し, # で -1 を表す.

## メモリ空間

命令メモリ, データメモリ, スタックメモリに分かれていて, それぞれ 243 要素まで持てる.

スタックへのアクセスは PUSH, POP, CALL 命令でのみ可能であり, スタックポインタは自動でインクリメント, デクリメントされる.

命令メモリにはユーザープログラムからは書き込みできない.

データメモリの 121 (0t11111) 番地は mmio に対応している.

## レジスタ

汎用レジスタは A, B, C の 3 つ存在する.
ただし A レジスタは多くの命令のソースレジスタとして暗黙的に使用される.

ADD, SUB, CMP の命令の結果の符号は 1 trit の符号レジスタに格納され, 条件付きジャンプ命令 (JP, JZ, JN) でのみ参照できる.

## 命令形式

- D: デスティネーションレジスタを A, B, C から 1 つ指定.
- R: ソースレジスタを A, B, C から 1 つ指定.
- I: 即値を -121 ~ 121 の範囲で指定.
- L: ラベルを指定.
- N: オペランドなし.

## IO

ASCII コードは 0 ~ 127 の範囲のみ対応し, -121 のオフセットを加えた値として入出力する.

例えば 'A' (0x41 = 65) は -56 として扱う.
